# eureka | Detección Autónoma de Fricción en UX

Plataforma inteligente de detección autónoma y análisis multimodal de patrones de fricción en la experiencia de usuario.

## Inicio Rápido

Para iniciar el servidor de desarrollo:

```bash
pnpm dev
```

Abre [http://localhost:3000](http://localhost:3000) en tu navegador para ver la aplicación.

## Stack Tecnológico

- **Framework**: Next.js 16 (App Router, Turbopack)
- **UI & Estilos**: Tailwind CSS 4, Radix/Base-UI, Lucide Icons, tw-animate-css
- **Tipografía**: Space Grotesk
- **Lenguaje**: TypeScript
